# Backfill Exception Report (Specification)

## Purpose

Operational report produced by **every** Batch 4 backfill migration. It records
each row the backfill could not map cleanly (or auto-corrected), so the platform
team can act. Generated by the migration runner; surfaced at
`/platform/subscriptions` (review queue) and stored for audit.

## Report Schema

| Field | Type | Description |
|-------|------|-------------|
| `report_run_id` | uuid | One id per backfill execution (correlates rows) |
| `migration` | text | e.g. `068_backfill_subscription_type` |
| `tenant_id` | uuid | Affected tenant |
| `subscription_id` | uuid \| null | Affected subscription (if applicable) |
| `entity` | text | `subscription` \| `tenant` \| `package` \| `quota` |
| `reason` | text | Why the row was flagged (maps to an AM-code, see Readiness Review) |
| `severity` | enum | `info` \| `warning` \| `critical` |
| `auto_fixed` | boolean | True if the backfill applied a safe default automatically |
| `applied_value` | jsonb | The value written (for auditability) |
| `manual_review_required` | boolean | True if a human must confirm/correct |
| `created_at` | timestamptz | When the exception was recorded |

## Severity Guidance

| Severity | Meaning | Example |
|----------|---------|---------|
| `info` | Deterministic mapping, no ambiguity | max_* → resource_limits |
| `warning` | Auto-fixed with an assumption | AM-1 interval guessed from period span; AM-2 `canceled → terminated` |
| `critical` | Cannot be safely auto-mapped | AM-3 tenant with no subscription; AM-4 is_active vs subscription conflict |

## Emission Rules (per migration)

- **067 resource_limits** → `info` rows only (deterministic).
- **068 subscription_type/lifecycle_state** → `warning` for span-guessed type (AM-1) and `canceled→terminated` (AM-2).
- **069 tenants.status** → `warning` for `expired→non_active`; `critical` for AM-3/AM-4.
- **070 quota migrate** → `info`; `warning` if a `tenant_quotas` row has no matching tenant.

## Output Format

The runner emits both:
1. A machine-readable JSON array (one object per exception, schema above).
2. A human summary: counts by `severity`, by `entity`, and a
   `manual_review_required` list with tenant/subscription ids.

## Acceptance

A backfill is **clean** when `critical = 0`. `warning` rows are acceptable but
must be triaged via the manual-review list before Legacy Removal phase.
