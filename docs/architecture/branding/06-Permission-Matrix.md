## Slug Change Policy

1. Tenant Owner requests slug change via support/admin
2. Super Admin reviews and approves
3. Slug change is a **paid service** (not free)
4. Old slug: redirect (301) to new slug for 90 days
5. After 90 days: old slug released for reuse
