# P0.9A.2 — Parser Contract (CSV Limitations)

> Documenting unsupported CSV features for transparency.

---

## Supported

| Feature | Status |
|---------|--------|
| Comma separator (`,`) | ✅ |
| Basic quoting (`"value"`) | ✅ |
| Quoted commas (`"Value, with comma"`) | ✅ |
| Empty trailing columns (`,,`) | ✅ |
| UTF-8 encoding | ✅ |
| CRLF and LF line endings | ✅ |

## NOT Supported (explicit limitations)

| Feature | Status | Reason |
|---------|--------|--------|
| Multiline quoted fields | ❌ | Not needed for purchase import |
| Escaped quotes (`""` → `"`) | ❌ | Use papaparse for full RFC 4180 |
| Semicolon separator (`;`) | ❌ | Only comma supported |
| Custom delimiters | ❌ | Only comma supported |
| Comments (`# comment`) | ❌ | Not part of purchase template |

## Future Upgrade Path

If full RFC 4180 compliance is needed:
- Install `papaparse` for full CSV parsing
- Replace `splitCsvLine()` with `Papa.parse()`
- All other contracts (ImportRow, ImportParseResult) remain unchanged
