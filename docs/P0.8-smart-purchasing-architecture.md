## 4. Product Matching Engine Design

```
Input: PurchaseDraftItem (with rawProductName)
         │
         ▼
  ┌─────────────────────────────┐
  │ 1. Exact Match              │
  │    products.name = raw      │ → confidence: 100%
  │    products.barcode = raw   │ → confidence: 100%
  └─────────────────────────────┘
         │ not found
         ▼
  ┌─────────────────────────────┐
  │ 2. Fuzzy Match              │
  │    Levenshtein distance     │
  │    Token matching           │
  │    Normalized: lowercase,   │
  │    remove special chars     │
  │                             │
  │    > 90% → confidence: HIGH │ auto-match
  │    80-90% → confidence: MED │ suggest
  │    70-80% → confidence: LOW │ review required
  │    < 70% → NO MATCH         │
  └─────────────────────────────┘
         │
         ▼
  ┌─────────────────────────────┐
  │ 3. No Match                 │
  │    → "Create New Product"   │
  │    → opens QuickCreateModal │
  └─────────────────────────────┘
```

### Fuzzy Matching Algorithm

```ts
function matchProduct(rawName: string, candidates: Product[]): MatchResult {
  const normalized = rawName.toLowerCase().replace(/[^a-z0-9\s]/g, '').trim();
  const tokens = normalized.split(/\s+/);

  for (const candidate of candidates) {
    const candidateNorm = candidate.name.toLowerCase().replace(/[^a-z0-9\s]/g, '').trim();

    // Exact after normalization
    if (candidateNorm === normalized) {
      return { productId: candidate.id, confidence: 100, method: 'exact' };
    }

    // Levenshtein
    const distance = levenshteinDistance(normalized, candidateNorm);
    const maxLen = Math.max(normalized.length, candidateNorm.length);
    const similarity = ((maxLen - distance) / maxLen) * 100;

    if (similarity >= 90) {
      return { productId: candidate.id, confidence: Math.round(similarity), method: 'fuzzy' };
    }
  }

  return { productId: null, confidence: 0, method: 'none' };
}
```

### Confidence Score Display

| Score | Color | Action |
|-------|-------|--------|
| 95–100% | 🟢 Green | Auto-match, no review needed |
| 80–94% | 🟡 Yellow | Suggestion, quick review |
| 60–79% | 🟠 Orange | Warning, review recommended |
| < 60% | 🔴 Red | Manual match or create new |

## 5. Tax Engine Design

### Settings (Pharmacy / Tenant level)

```ts
interface TaxSettings {
  purchaseTaxEnabled: boolean;
  purchaseTaxRate: number;       // e.g. 11 (percent)
  purchaseTaxMode: "inclusive" | "exclusive";
  // Inclusive: Price already includes tax → HPP = Price
  // Exclusive: Tax added on top       → HPP = Price + Tax
}
```

### Tax Calculation

```ts
function calculateTax(price: number, rate: number, mode: TaxMode): TaxResult {
  if (mode === 'inclusive') {
    const taxAmount = price - (price / (1 + rate / 100));
    return { taxAmount, priceBeforeTax: price - taxAmount, hpp: price };
  }
  // exclusive
  const taxAmount = price * (rate / 100);
  return { taxAmount, priceBeforeTax: price, hpp: price + taxAmount };
}
```

## 6. HPP Engine Design

```
HPP = Purchase Price + Tax Amount

Per-batch HPP:
  - Batch A purchased at Rp 15,000 + 11% tax = HPP Rp 16,650
  - Batch B purchased at Rp 14,000 + 11% tax = HPP Rp 15,540

Product average HPP (weighted):
  SUM(batch.hpp × batch.qty) / SUM(batch.qty)
```

## 7. Margin + Price Recommendation Engine

### Product Master Fields (new)

```ts
interface ProductPricing {
  targetMarginPercent: number;      // e.g. 35
  minSellingPrice: number | null;   // absolute floor
  maxSellingPrice: number | null;   // absolute cap
  priceLocked: boolean;            // if true, always use existing price
}
```

### Recommendation Algorithm

```ts
function recommendSellingPrice(
  hpp: number,
  product: ProductPricing,
  currentSellingPrice: number,
  previousPurchaseHpp: number
): PriceRecommendation {
  const recommended = hpp * (1 + product.targetMarginPercent / 100);

  // Cap/floor
  const capped = Math.max(
    product.minSellingPrice ?? 0,
    Math.min(product.maxSellingPrice ?? Infinity, recommended)
  );

  // Decision
  if (product.priceLocked) {
    return { price: currentSellingPrice, action: 'keep_existing', reason: 'Price locked' };
  }

  const priceChange = ((currentSellingPrice - capped) / currentSellingPrice) * 100;
  if (Math.abs(priceChange) < 5) {
    return { price: currentSellingPrice, action: 'keep_existing', reason: 'Minimal change' };
  }

  return { price: capped, action: 'use_recommended', reason: `HPP changed by ${priceChange.toFixed(1)}%` };
}
```

## 13. Risk Analysis

| Risk | Severity | Mitigation |
|------|----------|------------|
| **Duplicate purchases** (same OCR twice) | HIGH | Image hash dedup + OCR session cache |
| **OCR accuracy** (wrong product names) | HIGH | Human review gate + confidence score display |
| **AI parsing errors** (wrong JSON) | MEDIUM | Validation schema + human correction UI |
| **Tax calculation errors** | MEDIUM | Global locked setting + per-item preview |
| **Vendor lock (Google Vision)** | MEDIUM | Provider abstraction interface |
| **Performance** (large Excel files) | LOW | Row limit + chunked processing |
| **Cost** (OCR + AI per page) | MEDIUM | Dedup cache + image hash + batch processing |
| **Database growth** (OCR sessions) | LOW | Auto-cleanup old sessions after 90 days |
| **Existing flow breakage** | LOW | Additive only — zero changes to existing paths |
| **FEFO corruption** | LOW | Existing batch engine handles HPP per batch |

## 14. Cost Optimization Strategy

| Strategy | Detail |
|----------|--------|
| **Image hash cache** | Same image → reuse OCR result, never re-process |
| **OCR session TTL** | Delete raw OCR data after 90 days |
| **AI parser: cheapest first** | Gemini Flash (cheap) → fallback to Pro if low confidence |
| **Batch OCR** | Process multiple invoice pages in one API call |
| **Provider selection by volume** | Low volume: Google Vision (pay-per-use), High volume: negotiate |
| **Excel import: free** | No OCR/AI cost — only product matching (local compute) |

## 16. Architecture Principles

1. **Existing engine is sacred.** Never modify `addPurchase()`, `createBatch()`, `createStockMovement()`.
2. **Draft is always previewed.** Never auto-insert stock from any source.
3. **Human confirms manually.** OCR, Excel, API — all require human review.
4. **Engines are pure.** Tax, HPP, Margin engines have zero side effects.
5. **Providers are swappable.** OCR and AI providers behind interfaces.
6. **Hash dedup everything.** Never process the same invoice twice.
7. **Confidence displayed.** Every automated decision shows its confidence.
