## Existing Flow (Manual Purchase)

```
InventoryPageContent (tab: "purchase")
  ↓
InventoryPurchasePanel
  │
  ├── Form: supplier, dueDate, items[]
  │    PurchaseItem: { id, tenantId, productId, productName,
  │                    batchNumber, expiredDate, quantity,
  │                    unitPrice, sellingPrice }
  │
  └── handleSubmit()
       │
       ▼
  useInventoryStore.getState().addPurchase(invoice)
       │
       ├── 1. Auto-generate batch numbers (if empty)
       │      Format: AUTO-{invoiceNumber}-{NN}
       │
       ├── 2. supplierRepo.createPurchaseInvoice()
       │      INSERT INTO purchase_invoices
       │      INSERT INTO purchase_items
       │
       ├── 3. For each item:
       │      ├── inventoryRepo.getBatchesByProduct()
       │      ├── If batch exists → updateBatchQuantity()
       │      └── If new → inventoryRepo.createBatch()
       │           INSERT INTO product_batches
       │
       ├── 4. inventoryRepo.createStockMovement()
       │      INSERT INTO stock_movements (type: "purchase")
       │
       └── 5. Reload state from DB
              productRepo.getProducts()
              supplierRepo.getSuppliers()
              → set({ batches, suppliers, invoices, ... })
```

## PurchaseInvoice → addPurchase() Payload

```ts
interface PurchaseInvoice {
  id: string;              // UUID
  tenantId: string;        // from auth context
  invoiceNumber: string;   // auto: INV-P-YYYYMMDD-HHMM
  supplierId: string;      // FK → suppliers.id
  supplierName: string;    // denormalized
  purchaseDate: string;    // ISO
  dueDate?: string;        // optional
  status: PurchaseStatus;  // "unpaid" on create
  totalAmount: number;     // SUM(qty × unitPrice)
  paidAmount: number;      // 0 on create
  items: PurchaseItem[];
}

interface PurchaseItem {
  id: string;
  tenantId: string;
  productId: string;       // FK → products.id
  productName: string;
  batchNumber: string;     // auto-generated if empty
  expiredDate: string;     // required
  quantity: number;        // min 1
  unitPrice: number;       // > 0
  sellingPrice: number;    // > 0
}
```

## Draft → Invoice Mapping (P0.8H Adapter)

```
PurchaseDraft                    → PurchaseInvoice
  draft.id                       → invoice.id
  draft.tenantId                 → invoice.tenantId
  draft.invoiceNumber ?? auto    → invoice.invoiceNumber
  draft.supplierId               → invoice.supplierId
  draft.supplierName             → invoice.supplierName
  draft.purchaseDate             → invoice.purchaseDate
  draft.dueDate                  → invoice.dueDate
  "unpaid"                       → invoice.status
  calculateDraftTotals().grand   → invoice.totalAmount
  0                              → invoice.paidAmount

PurchaseDraftItem                → PurchaseItem
  item.id                        → item.id
  ""                             → item.tenantId (filled by addPurchase)
  item.matchedProductId          → item.productId
  item.rawProductName            → item.productName
  item.batchNumber ?? ""         → item.batchNumber
  item.expiredDate ?? now        → item.expiredDate
  item.quantity                  → item.quantity
  item.enteredBuyPrice           → item.unitPrice
  item.currentSellingPrice       → item.sellingPrice
```

## What the Adapter MUST NOT do

```
❌ supplierRepo.createPurchaseInvoice()    ← addPurchase does this
❌ inventoryRepo.createBatch()             ← addPurchase does this
❌ inventoryRepo.updateBatchQuantity()     ← addPurchase does this
❌ inventoryRepo.createStockMovement()     ← addPurchase does this
❌ Any direct INSERT/UPDATE on DB          ← addPurchase does this
✅ Call addPurchase(invoice)               ← ONLY this
```
