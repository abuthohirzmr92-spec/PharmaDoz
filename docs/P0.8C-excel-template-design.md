### PurchaseItem Structure (existing)

```ts
  id: string;
```

### Current Save Flow (PROTECTED — no changes)

```
handleSubmit()
  ├── Validate: supplier exists
  ├── Validate: each item has productId, productName, quantity > 0
  ├── Validate: each item has expiredDate, unitPrice > 0, sellingPrice > 0
  ├── Generate: invoiceNumber = INV-P-YYYYMMDD-HHMM
  ├── Calculate: totalAmount = SUM(qty × unitPrice)
  ├── Build: PurchaseInvoice object
  └── Call: inventoryStore.addPurchase(invoice)
       ├── Auto-generate batch numbers (if empty)
       ├── supplierRepo.createPurchaseInvoice()
       ├── inventoryRepo.createBatch() / updateBatchQuantity()
       ├── inventoryRepo.createStockMovement(type: purchase)
       └── Reload state from DB
```

### Validation Rules (per cell)

```ts
const CSV_RULES = {
  nama_produk: {
    required: true,
    minLength: 2,
    maxLength: 255,
```

### Excel-Specific Handling

| Feature | Implementation |
|---------|---------------|
| Multiple sheets | Only read first sheet |
| Merged cells | Unmerge before parsing |
| Date formatting | Convert Excel serial dates → ISO string |
| Number formatting | Strip currency symbols (Rp, $), thousands separators |
| Empty rows | Skip entirely |
| Formula cells | Read computed value, not formula |
| Hidden rows | Skip hidden rows |
| Large files | Max 500 rows, 10MB file size |

## STEP 6 — AUTO PRICE ENGINE COMPATIBILITY

### Behavior (preserves existing logic)

```
For each imported item:

IF product matched (exact or fuzzy):
  1. Load products.default_price          → pre-fill harga_beli (if empty)
  2. Load products.default_selling_price  → display current selling price
  3. Load last purchase_items.unit_price  → display previous purchase price
  4. Load last purchase supplier_name     → pre-fill supplier (if empty)

  Calculate:
    HPP = harga_beli + (harga_beli × tax_rate)
    Margin = current_sell / HPP - 1
    Recommended = HPP × (1 + target_margin)

  Warnings:
    - "Harga naik 15% dari terakhir" (if buy > prev × 1.15)
    - "Margin di bawah target" (if margin < target)

IF product NOT matched:
  - harga_beli = 0 (user must fill)
  - No auto-fill
  - Flag for manual review
```

### Same logic as existing manual form

The `handleItemChange` in `inventory-purchase-panel.tsx:113-119` auto-fills `unitPrice` and `sellingPrice` from `products.default_price` and `products.default_selling_price`. The import adapter must replicate this behavior — not replace it.

## STEP 8 — DUPLICATE HANDLING

### Detection

Two rows with same `product_name` (after normalization) → flag as potential duplicate.

```ts
function detectDuplicates(items: PurchaseDraftItem[]): DuplicateGroup[] {
  const groups = new Map<string, number[]>();  // normalized name → row indices
  for (const [i, item] of items.entries()) {
    const key = normalizeName(item.rawProductName);
    const indices = groups.get(key) || [];
    indices.push(i);
    groups.set(key, indices);
  }
  return [...groups.entries()]
    .filter(([, indices]) => indices.length > 1)
    .map(([name, indices]) => ({ name, indices }));
}
```

### Merge Options

| Option | Behavior | Example |
|--------|----------|---------|
| **Merge** | Sum qty, keep lowest price? average? | Paracetamol: 10 + 5 = qty 15 |
| **Keep Separate** | Treat as different batches | 2 separate purchase items |
| **Delete One** | Remove duplicate row | Keep row with more data |
