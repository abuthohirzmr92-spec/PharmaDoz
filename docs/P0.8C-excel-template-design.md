## STEP 5 — AUTO PRICE DESIGN

### When Product Matches

```
Product found (exact/fuzzy match)
  ↓
Load product master:
  ├── products.default_price           → pre-fill buy_price (if empty)
  ├── products.default_selling_price   → display current_selling_price
  └── products.target_margin           → calculate recommended_selling_price
  ↓
Load purchase history (last 1):
  ├── purchase_items.unit_price        → previous_buy_price (display)
  └── purchase_invoices.supplier_name  → suggest_supplier (display)
  ↓
Calculate:
  ├── HPP  = buy_price + tax
  ├── Margin = current_sell / HPP - 1
  └── Recommended = HPP × (1 + target_margin)
  ↓
Display warnings:
  ├── "Harga naik 15% dari pembelian terakhir" (if buy > prev × 1.15)
  ├── "Harga turun 20% dari pembelian terakhir" (if buy < prev × 0.80)
  └── "Margin di bawah target 35%" (if margin < target)
```

### When Product NOT Found

```
No match / low confidence
  ↓
Flag for manual review:
  ├── match_status = "unmatched" / "low"
  ├── color = 🔴 / 🟠
  └── Admin must manually select product or create new
  ↓
Cannot auto-fill:
  ├── buy_price = user input (required now)
  └── no pricing recommendations
```

### Processing Flow

```
1. Upload file
2. Parse rows → PurchaseDraftItem[]
3. Run ProductMatcher on each item
4. Run AutoPriceEngine on matched items
5. Display Preview Grid with badges + warnings
6. Admin reviews:
   ├── Fix matches (rematch / create product)
   ├── Edit prices / qty
   ├── Delete rows
   └── Merge duplicates
7. Save as PurchaseDraft (status: "reviewed")
8. Later: admin confirms → push to existing Purchase Engine
```
