## Architecture

```
CSV File (.csv)
  ↓
parser.ts (parseCsv)
  ↓ CsvRow[]
  ↓
mapper.ts (mapCsvRowsToDraftItems)
  ↓ PurchaseDraftItem[]
  ↓
csv-service.ts (importCsvToDraft)
  ├── match-engine (matchProduct per item)
  └── warning-engine (generateWarnings per item)
  ↓
PurchaseDraft { status: "ready" | "has_warning" | "has_error" }
  ↓
Human Review (UI — future)
  ↓
confirmDraft() (draft-confirm-adapter)
  ↓
addPurchase() (EXISTING ENGINE)
  ↓
Inventory
```

## CSV Format

```csv
nama_produk,qty,harga_beli,batch_number,expired_date
Paracetamol 500mg,10,15000,BATCH-001,2027-06-19
Amoxicillin 500mg,20,25000,,2027-12-31
Vitamin C,50,8500,,
```

| Column | Required | Type |
|--------|----------|------|
| `nama_produk` | ✅ | text (min 2 chars) |
| `qty` | ✅ | integer (min 1) |
| `harga_beli` | ✅ | number (min 0) |
| `batch_number` | ❌ | text |
| `expired_date` | ❌ | date string |

## Safety Audit

| Check | Result |
|-------|--------|
| Calls addPurchase()? | ❌ No — draft returned for review |
| Direct DB writes? | ❌ No |
| Repository access? | ❌ No |
| Stock movements? | ❌ No |
| Supabase access? | ❌ No |
| Store imports? | ❌ No |
| Bypasses match-engine? | ❌ No — always runs matching |
| Bypasses warning-engine? | ❌ No — always runs warnings |
| Bypasses confirmDraft()? | ❌ No — draft must be reviewed |
