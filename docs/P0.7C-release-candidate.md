### ⚠️ Vercel Preview Issue

Vercel preview deployments show "Layanan sedang tidak tersedia" because `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are empty in the Vercel project environment.

**Fix:** Set these in Vercel dashboard → Project → Settings → Environment Variables:
```
NEXT_PUBLIC_SUPABASE_URL = https://<project>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY = <anon-key>
```
