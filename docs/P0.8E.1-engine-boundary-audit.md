## Architecture Rules (enforced)

1. **Store** = state only. Only `set()`. No algorithms.
2. **Engine** = pure functions only. No `set()`. No side effects.
3. **Service** = orchestration only. Coordinates engines + writes to store.
4. **No engine may call another engine directly.** Services orchestrate.
5. **No circular dependencies.**
6. **No God Engine.** Each engine has one responsibility.
7. **No God Store.** Store only manages drafts state.
