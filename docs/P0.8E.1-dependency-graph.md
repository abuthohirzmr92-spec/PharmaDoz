## Forbidden Dependencies

```
❌ Engine → Store      (engine must never call set())
❌ Engine → Engine     (engine must not depend on another engine; services orchestrate)
❌ Store → Engine      (store must not contain business logic)
❌ Store → Service     (store is lowest layer)
✅ Service → Engine    (service orchestrates engines)
✅ Service → Store     (service writes to store)
✅ UI → Service        (UI calls service)
✅ UI → Store (read)   (UI reads store state)
```
