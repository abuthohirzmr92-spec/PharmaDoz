### Forbidden Dependencies Found

#### ⚠️ Engine → Engine: `draft-engine.ts` imports `warning-engine.ts`

**File:** `src/lib/purchasing/draft-engine.ts:14`
```ts
import { generateWarnings, hasCriticalWarnings } from "./warning-engine";
```

**Risk:** LOW. These two engines are tightly coupled by design — `validateDraft()` needs warnings to determine draft status. Breaking this would require `validateDraft()` to accept pre-computed warnings as parameters, adding boilerplate to every service call with no benefit.

**Recommendation:** ACCEPT this dependency as a pragmatic exception. `draft-engine` and `warning-engine` form a validation subsystem. They are not independent engines but validation layers.
