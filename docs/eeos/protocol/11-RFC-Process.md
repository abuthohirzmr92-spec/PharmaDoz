# EEP v1.0 — RFC Process

## Stages

| Stage | Owner | Duration | Exit |
|-------|-------|:------:|------|
| **Draft** | Author | — | Ready for discussion |
| **Discussion** | Community | 2 weeks minimum | All feedback addressed |
| **Review** | Protocol Board | 1 week | Approved or Rejected |
| **Accepted** | Protocol Board | — | Implementation begins |
| **Rejected** | Protocol Board | — | Closed with rationale |
| **Implemented** | Author + Maintainers | Per sprint | Code merged, tests pass |
| **Deprecated** | Protocol Board | — | Superseded by new RFC |
| **Archived** | Protocol Board | — | Historical record |

## RFC vs ADR

| Aspect | RFC | ADR |
|--------|-----|-----|
| Scope | Protocol/API design | Architecture decision |
| Audience | All EEOS components | Architecture Board |
| Process | Community discussion | Board review |
| When Required | New protocol feature, breaking change | Major design decision |
