# EEP v1.0 — Protocol Governance

## Protocol Board

| Role | Responsibility |
|------|---------------|
| Protocol Architect | Protocol design, RFC approval |
| Core Maintainer (2) | Implementation review, compatibility verification |
| Community Representative | Community feedback, adoption tracking |

## RFC Workflow

```
Draft → Discussion → Review → Accepted / Rejected
                                ↓
                           Implemented
                                ↓
                           Deprecated
                                ↓
                            Archived
```

## Protocol Amendments

- Minor changes: Protocol Board majority
- Major (breaking) changes: Protocol Board + Architecture Board unanimous
- Emergency amendments: Protocol Architect + 1 Core Maintainer (retrospective review required)

## Breaking Changes

- Require new MAJOR protocol version
- Old version supported for 2 EEOS major versions
- Migration guide mandatory
- Marketplace engines given 6 months to update
