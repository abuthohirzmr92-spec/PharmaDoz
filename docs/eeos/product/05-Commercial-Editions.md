# EEOS — Commercial Editions v1.0

## Community (Free, Open Source)

- Full Runtime + EDK + Execution Engine
- All certified engines
- CLI
- Single project
- Local workspace
- Community support

## Professional (Paid, Per-Seat)

- Everything in Community
- Workspace with history
- Dashboard (Web UI)
- Multi-project support
- Email support
- LTS releases (18 months)

## Enterprise (Paid, Organization)

- Everything in Professional
- Organization-wide policies
- SSO integration
- Audit trail
- Compliance reporting
- Dedicated support
- Custom engine development
- LTS releases (3 years)

## Cloud (SaaS)

- Everything in Enterprise
- Managed infrastructure
- Cross-project analytics
- Team collaboration
- Automatic updates
- 99.9% SLA

## Upgrade Path

```
Community → Professional → Enterprise → Cloud
```

All editions share the same core Runtime. Editions differ only in available modules, support, and infrastructure. No code fork. Feature flags govern edition capabilities.
