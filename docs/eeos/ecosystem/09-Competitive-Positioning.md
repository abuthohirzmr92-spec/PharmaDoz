# EEOS — Competitive Positioning v1.0

## Category Definition

EEOS occupies a distinct category: **Engineering Execution Orchestration**.

## Adjacent Categories

| Category | Examples | EEOS Relationship |
|----------|----------|-------------------|
| **CI/CD** | GitHub Actions, Jenkins | EEOS governs engineering PROCESS; CI/CD executes BUILDS. Complementary. |
| **Project Management** | Jira, Linear | EEOS governs engineering EXECUTION; PM tools manage SPRINTS. Complementary. |
| **Architecture Governance** | ADRs (manual), ArchUnit | EEOS AUTOMATES architecture compliance. EEOS replaces manual ADR tracking. |
| **Code Review** | GitHub PRs, Gerrit | EEOS enforces ARCHITECTURE compliance at review time. Complementary. |
| **Engineering Analytics** | CodeClimate, SonarQube | EEOS provides PROCESS analytics, not code quality. Complementary. |

## What EEOS Intentionally Does NOT Replace

- ❌ CI/CD pipelines (build, test, deploy)
- ❌ Project management (sprint planning, backlog)
- ❌ Code hosting (GitHub, GitLab)
- ❌ Code quality analysis (linting, static analysis)
- ❌ Monitoring (Datadog, Sentry)

## What EEOS Uniquely Provides

- ✅ Deterministic engineering workflow
- ✅ Automated architecture compliance
- ✅ Policy-driven governance
- ✅ Engine Development Kit for custom workflows
- ✅ Certified engine marketplace
- ✅ Framework-independent (works with any stack)
