# EKG v1.0 — Roadmap

## Phases

| Phase | Name | Capability | Target |
|:-----:|------|-----------|:------:|
| **1** | Manual Knowledge Registry | Entity model, relationships, lifecycle defined. Human-curated. | Now |
| **2** | Automatic Knowledge Index | Entities auto-indexed from architecture docs, ADRs, reports | EEOS v3.1 |
| **3** | Knowledge Resolution | Deterministic query resolution, cross-references | EEOS v3.2 |
| **4** | Cross-reference Engine | Automatic relationship detection, broken reference alerts | EEOS v4.0 |
| **5** | Knowledge Graph | Full graph database, relationship traversal, visualization | EEOS v4.x |
| **6** | Semantic Search | Natural language queries over knowledge graph | EEOS v5.0 |
| **7** | AI Knowledge Assistant | AI-powered knowledge discovery, recommendation | EEOS v5.x |
| **8** | Enterprise Knowledge Platform | Multi-org knowledge federation, compliance reporting | EEOS v6.0 |

## Current Status

```
Phase 1: COMPLETE (architecture defined)
Phase 2-8: FUTURE
```
