# ACE v1.0 — Roadmap

## Phases

| Phase | Name | Capability | Target |
|:-----:|------|-----------|:------:|
| **1** | Manual Compliance | Rule system, evidence model, violation model defined. Human executes checks. | Now |
| **2** | Repository Validation | Automated checks: file structure, imports, naming conventions | EEOS v3.1 |
| **3** | Protocol Validation | Automated manifest + contract validation | EEOS v3.2 |
| **4** | Architecture Validation | Blueprint ↔ Code consistency checks | EEOS v3.3 |
| **5** | Code Analysis | AST-based rule checking (no React in domain, no Zustand in services) | EEOS v4.0 |
| **6** | AI Assisted | AI suggests fixes for violations | EEOS v4.x |
| **7** | Continuous Compliance | Pre-commit hooks, CI integration, real-time violation detection | EEOS v5.0 |
| **8** | Enterprise Governance | Organization-wide policy enforcement, compliance dashboards, audit trails | EEOS v5.x |

## Current Status

```
Phase 1: COMPLETE (architecture defined)
Phase 2-8: FUTURE
```
