# ACE v1.0 — Rule Pack Architecture

## Standard Rule Packs

| Pack | Contents | Edition |
|------|----------|:------:|
| **Core** | Constitution, ADR, Policy, Repository | All |
| **Architecture** | Blueprint, Invariants, Principles | Pro+ |
| **Security** | Dependency audit, secret detection | Pro+ |
| **Performance** | Budget enforcement, bundle size | Pro+ |
| **Documentation** | Completeness, cross-references | All |
| **Marketplace** | Manifest, compatibility, certification | Pro+ |
| **Enterprise** | SSO, audit trail, compliance reporting | Enterprise |
| **Plugin** | Third-party engine validation | All |

## Extensibility

Third-party rule packs follow the same Rule System. Published to Marketplace. Versioned independently. Certified by Certification Board.
