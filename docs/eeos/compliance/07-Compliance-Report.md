# ACE v1.0 — Compliance Report

## Required Fields

| Field | Description |
|-------|-------------|
| reportId | Unique identifier |
| timestamp | ISO8601 |
| scope | What was checked (module, epic, sprint) |
| rulesEvaluated | Count of rules checked |
| rulesPassed | Count passed |
| rulesFailed | Count failed |
| violations | Violation[] |
| score | 0–100 composite |
| confidence | 0.0–1.0 |
| certificationStatus | Current badge status |
| recommendations | Actionable recommendations |
| nextReview | Recommended next review date |

## Score Calculation

```
Score = (rulesPassed / rulesEvaluated) × 100

Weighted by severity:
  INFO × 1, WARNING × 2, MINOR × 4, MAJOR × 8, CRITICAL × 16, BLOCKING → 0
```

## Machine Readable

Reports are JSON. Human-readable summaries generated by Dashboard. CLI outputs text format.
