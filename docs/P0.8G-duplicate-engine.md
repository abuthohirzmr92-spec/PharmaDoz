## Detection Strategies

| # | Strategy | Confidence | Trigger |
|---|----------|------------|---------|
| 1 | Barcode | 100% | `rawBarcode` non-empty and identical |
| 2 | Exact name | 95% | `rawProductName` identical (case-insensitive) |
| 3 | Matched product ID | 90% | Both items matched to same DB product |
| 4 | Normalized name | 85% | Names identical after stripping punctuation |
| 5 | Token similarity | 80%+ | Token overlap ≥75% |

## Deduplication Logic

Items may appear in multiple groups (e.g., same barcode AND same name).  
The engine keeps only the **highest confidence** group per item.  
A group is only returned if ≥2 items remain after dedup.

## Examples

### Barcode match (100%)

```
Item A: barcode="8991234567890", name="Paracetamol 500mg"
Item B: barcode="8991234567890", name="Paracetamol 500mg IFARS"
→ Duplicate by barcode, confidence 100%
```

### Exact name match (95%)

```
Item A: name="Amoxicillin 500mg", barcode=null
Item B: name="Amoxicillin 500mg", barcode=null
→ Duplicate by exact name, confidence 95%
```

### Matched product ID (90%)

```
Item A: matchedProductId="uuid-123", name="Paracetamol Tab"
Item B: matchedProductId="uuid-123", name="Paracetamol 500mg Tablet"
→ Duplicate by matched product, confidence 90%
```

### Normalized name (85%)

```
Item A: name="PARACETAMOL 500 MG !!!"
Item B: name="paracetamol 500 mg"
→ Normalized: "paracetamol 500 mg" = "paracetamol 500 mg"
→ Duplicate, confidence 85%
```

### Token similarity (80%+)

```
Item A: name="Paracetamol 500mg Tablet" (tokens: paracetamol, 500mg, tablet)
Item B: name="Paracetamol 500mg"        (tokens: paracetamol, 500mg)
→ B's tokens 100% contained in A → overlap = min(1.0, 0.67) = 0.67 → below threshold
→ No match
```

```
Item A: name="Amoxicillin 500 Capsule"
Item B: name="Amoxicillin 500 Kapsul"
→ tokens: ["amoxicillin","500","capsule"], ["amoxicillin","500","kapsul"]
→ overlap: "amoxicillin" + "500" = 2/3 ≈ 0.67 → below threshold
→ No match (language difference — future enhancement)
```
