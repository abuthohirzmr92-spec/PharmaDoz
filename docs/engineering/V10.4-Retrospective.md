# 6. LESSONS LEARNED — PROGRAM

1. **Type-level enforcement > documentation.** `AllocationEntry` tidak bisa menyimpan `sellingPrice` — compiler memverifikasi. Ini mencegah seluruh kelas bug.

2. **Evolutionary refactor works at scale.** 4 sprints, 14 stories, 132 tests. Zero big bangs. Zero business rule changes. Zero production incidents.

3. **Dual-write is the ultimate safety net.** Setiap sprint bisa di-deploy independen. Old path selalu jalan. Rollback 1-3 jam.

4. **Blueprint LOCKED prevents scope creep.** 4 sprints, 0 scope changes. Setiap "sambil perbaiki X" ditolak dengan referensi Blueprint.

5. **Architecture grep is binary and fast.** "Apakah ada import inventory-store dari hook?" — jawaban dalam 1 detik. Tidak ada "mungkin".

6. **batchId is the canonical domain key.** Array index coupling antara dua domain object adalah fragile. Board Review menemukan ini di V10.3.

7. **ADR process prevents hasty decisions.** ADR-006 (Sales Unit) ditemukan saat sprint → dibuat ADR → status PROPOSED. Tidak dicampur dengan sprint.

8. **Pre-existing test failures compound.** 16 failures tidak berkurang dari V10.2 ke V10.4. Harus di-address di V11.0 sebelum menjadi lebih besar.
