## Collision Scenarios

| Scenario | Risk |
|----------|------|
| Two Draft items with same UUID | ❌ Impossible — `crypto.randomUUID()` guarantees uniqueness |
| Two DuplicateGroups with same ID | ❌ Impossible — `dup-{type}-{ids}` is deterministic per item set |
| Draft ID collision | ❌ Practically impossible — UUID v4 collision probability ≈ 0 |
